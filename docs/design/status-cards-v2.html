四个格子，矮下来、居中、配上图标

你原话是「连接、上下文、子任务、子代理这个卡片的 UI 很难看，太高了，而且没居中， 最好能加点图标啥的」。这一页是同一排状态在三种做法下的样子 —— 都只动这个组件（StatusCardView），转写区和协议一行不改。

问题不是"信息多余"，是**四层叠在一起**：标签一行、值一行、副行一行、指示器一行 —— 而每一层都只占半行高，四张卡被最高的那张顶到 80px。再加上：

  • 内容**全部靠左**（副行还靠右），四张卡里三种对齐方式
  • 值有 11px / 12px / 15px 三种字号，扫一眼分不出哪个是重点
  • 没有图标：四张卡只能靠文字辨认，"2" 到底是子代理还是什么，得读标签

三条都不动的：四张卡始终在（没内容时收边，不隐藏）、子任务/子代理可点开详情、卡片等宽。

四条细节：三个方案都得给答案

① 图标从哪来
平台图标 自绘

四个都自绘（Java2D，同现有的 IndicatorView），改过一次主意： 落地时发现平台图标（AllIcons.Toolwindows.Task、AllIcons.General.Groups， 都已核对存在）是**固定颜色**的，而icon 必须跟着色调变 —— 连接卡的 "已连接 / 正在载入 / 启动失败"就靠这一处区分。混着用会在同一行里露出 "系统色图标 + 主题色图标"两种画风，所以四个统一自绘。
图标固定 14×14，按 16×16 的方格画再整体缩放，颜色走 toneColor（绿 / 琥珀 / 红 / 灰），深浅色主题自动跟。

我推荐甲

它把"太高"这件事的**根**解决了：四层内容不是多余，是排得散。 两行一收，标签与值各自居中，80px 直接变 42px；副行搬进 tooltip 与详情浮层， 信息一点没丢。图标 + 标签同框也让四张卡第一次能靠形状被认出来。

乙最矮、也最漂亮，但它把"标签"整个撤了 —— 你在用第 20 次的时候不觉得， 第 1 次看见 2/4 和 2 并排会愣一下。它更适合你已经熟了这个插件之后。 丙更像 IDE 的状态栏，安静，代价是那四格的可点性会被弱化。

顺带一提：三个方案都把"值"统一成 13px，现在 11/12/15 三种字号那套（bigValue）可以退休了。
