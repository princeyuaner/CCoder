④ 颜色对照（这几个数是算出来的，不是挑的）

用途现在建议（深色）建议（浅色）对底色对比度
行内代码 选中块底色 #7fb0ff #1f6feb 1.6:1 → 6.2:1 / 4.8:1
小节标题 次要文字色 #b6bcc6 #6b7078 3.4:1 → 8.1:1
正文 跟组件前景走（本来就够亮，不动） —
取色不写死：卡片落在哪个底色上，主题不保证（Darcula / Material / 高对比）。 所以实现时按实测亮度选档 —— 候选色算一遍对比度，低于 4.5:1 就往亮里走一档。 唯一必须换掉的是来源本身：getTreeSelectionBackground 语义上就是"底色"， 它去当"文字色"用，深色主题下必然出事。
