计划文本怎么渲染 · 四个方案

截图里那段字是 Markdown —— 模型写的计划原文。权限框现在把它塞进 JBTextArea（纯文本组件）， 所以 #、** 这些记号原样铺了出来：不是在渲染，是在显示源码。

可行性先说清：权限框是 Swing。Swing 能做的是 JEditorPane 的 HTML 3.2 （标题 / 粗体 / 等宽 / 列表 / 分隔线 / 底色 / 左右缩进 / 表格），没有圆角、阴影、flex 布局 —— 下面每个方案都标了它落不落在这一档里。要走完整 CSS，只能把计划搬到转写区（那边是 JCEF）。

A轻 Markdown：记号变成样式

只做四件事：标题变大变粗、**x** 真加粗、反引号变等宽、段落之间留空。内容一个字不改，也不加任何装饰。

Swing 可做：JEditorPane HTML 改动最小：只换渲染组件 + 一个 Markdown→HTML 转换 风险最低：观感与现在同族

怎么选

方案像什么Swing代价
A 轻 Markdown一份纯文本，但记号没了直接可做最小：一个转换函数 + 换组件
B 文档式内部设计稿可做（色条要凑）多几条样式映射
C 卡片式网页打折要真的好看得搬到 JCEF
D 摘要点摘要卡可做与"审批要看得到内容"那条规矩冲突，要另开全文入口

我的建议：**先做 A**（成本最小、把"在看源码"这件事解决掉），观感真要再进一步就照 B 调。 C 留到"计划也进转写区"那天 —— 那时用现成的 Markdown.tsx 就行，一行 CSS 都不用新写。 D 我不建议：这个仓库为"审批要看得见内容"专门改过一次（见 PermissionQueue.kt 里 "看不到内容的审批不是审批"），摘要点等于把那条改回去一半。
