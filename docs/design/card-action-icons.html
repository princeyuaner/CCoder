动作图标：候选表

连接卡右上角放「清空会话」、上下文卡右上角放「压缩上下文」。常驻显示（不靠悬停 —— 悬停那一版实测点不到）。 每张候选都按真实尺寸 14px（左边小框）与放大版（右边）各画一遍：小尺寸下读得出来的才算数。

灰色是常态色、红/蓝是悬停时的着色（悬停 = 指针压上去，底色亮起来）。 颜色只是提亮，形状本身要能自己站住。

已定 · 2026-09-17：清空 = A 扫把（实心帚头），压缩 = E 压进托盘。 已按这两个图形实现（`StatusCardView.paintBroom` / `paintCompress`）， 落地的规格在 docs/superpowers/specs/2026-09-17-card-actions-design.md §3.4。

一 · 清空会话（连接卡）

语义：开一条新会话、上下文清空 —— 不删任何东西（旧会话留在磁盘上，列表里能切回来）。所以垃圾桶是错的：它承诺了"删掉"。

A · 扫把（实心帚头）已选

最像扫把的一版：细柄 + 一块实心帚头。风险：小尺寸下柄与头容易糊成一个点。

B · 扫把（鬃毛张开）

"毛"的意思最足。风险：四根线在小尺寸下可能看着像扇形/火花。

C · 掸子 / 鸡毛掸

竖柄 + 三根张开的毛，比 B 稳（对称、粗）。

D · 一抹 / 擦拭

一块橡皮擦 + 一道擦过的痕。好认，但"清空"的意思要靠 tooltip 补。

E · 重置箭头 ↺

"重来一遍"最通用、最小尺寸下最稳。但它与"清空"的差别是：会话对象也换了。

F · 垃圾桶（对照）

最一眼认出的"删除"。语义是错的（我们不删东西），列在这儿当参照。

二 · 压缩上下文（上下文卡）

语义：把这段对话压成摘要、腾出上下文空间。界面上的记录不动，对话在 CLI 那边被总结。

A · 对射实心三角（沙漏）

现在实现的就是它。清楚、对称，但更像"沙漏/时间"。

B · 对射箭头（带杆）

带杆的箭头方向最明确（"往里挤"）。小尺寸下杆会短到看不见，只剩两个 V。

C · 内折括号 ⊐⊏

"从两头往中间收"——工业界面里很常见的压缩符号，最小尺寸下也稳。

D · 双折角（unfold_less 标准形）

与"展开"是一对官方反义图形。小尺寸下容易读成叉（实现时就是这样）。

E · 压进托盘已选

"往下收进盒子"。意思到位，但小尺寸下托盘那两笔会糊。

F · 两条横杠收拢

"两条边靠拢"最抽象，但也最安静 —— 不会和卡上别的图形抢注意力。
