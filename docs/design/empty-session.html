空会话时，那块地方放什么

四个方向：两个"说话"的（信标 / 示例），一个"教用法"的（上手卡），一个只做装饰的（水印）。下面每张都按真实面板尺寸摆好，请看形状和气质，文案只是占位。

2026-10-10 选定：方案乙。实装时卡片上没有"Enter 发送 · Shift+Enter 换行"那行 —— 输入框的占位符里已经写着它（而且它跟着设置里的发送约定走，见 Composer.kt）， 卡上再印一份迟早会说岔。实装见 web/src/components/EmptyState.tsx； 空态的开关是 Kotlin 推来的 fresh 标记（不是"items 为空"—— 切换会话的回放真空期会因此闪卡，见 Transcript.tsx 的判据注释）。

现状与共同前提

现状：新会话时转写区只有一条居中的「会话已就绪」系统提示，其余整块背景空着（见用户截图）。

  • 只在没有任何内容项时出现 —— 新会话、/clear 之后；来了第一条消息就整体消失，不留在时间线里。
  • 「会话已就绪」的去向：甲 / 乙 / 丙 把它折进空态（顺带修掉"第一条消息上方永远挂着一条系统提示"）；丁 保留原样。
  • 恢复的历史会话有内容，不走这条路径。
  • 文案全部进 CcoderBundle 中英双语；420px 与 751px 两档宽度都成立（页尾有窄栏复核）。
  • 实现代价：甲 / 乙 / 丁是纯网页层的一条渲染分支；丙多一条桥接操作（点按 → 填入 Swing 输入框）。
