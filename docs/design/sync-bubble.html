同步跑完，卡上冒一句

一轮同步真的动了文件时，在同步卡上弹一个小气泡，说清"同步了哪些"，3 秒后自己关。 下面四种弹法都按真机尺寸画（面板 420px、五张卡每张 76.8px），差别在内容多少、 从哪儿冒出来、以及那 3 秒怎么算。

约束一 · 数据要先补一口

快照里今天只有计数（复制 3、删除 1）与失败/提醒明细，没有文件名。名字在 RoundReport.copies / deletes 里，随快照带一批上来即可。 第一轮全量可能一万多个 —— 必须截断，气泡只可能报"前 N 条 + 还有 M 个"。

约束二 · 什么时候弹

一轮跑完就推一次快照（静默期 1.5s，密集改动时几秒一轮）。 连着几轮不能叠一堆气泡：同一位置只留一个，内容换成最新的、3 秒重新计时。 纯"无变化"那轮（稳态下的大多数）不弹。

约束三 · 3 秒是按"读一行"算的

一行标题 + 两三条短路径，3 秒够；四行以上读不完。三种补偿：① 只报数，明细点开； ② 悬停时不计时（要自己做，平台气泡的 setFadeoutTime 不支持暂停）； ③ 干脆不自动关，但那就不叫"提示"了。

约束四 · 位置与焦点

同步卡在面板底部往上数第二张（x 89–165），气泡往上弹才能压住转写区而不是盖住输入框。 300px 宽的气泡没法居中贴那张卡，只能贴卡的左边缘向右长（同详情浮层那条 popupCardX 的规矩）。绝不能抢焦点 —— 你可能正在打字。

  3. 首轮全量：计数照报（"已同步 412 个文件"），列表只有三行，用时超过一秒换成 61s （"61000 毫秒"在一行标题里没人读得下去）。

一处与图不同的地方：数据取的是 RoundReport.copiedRel / deletedRel （**做成的**），不是 copies / deletes（计划，含失败的）。 为这个专门给报告加了那两个字段 —— 拿计划去报就是把没过去的说成过去了。
