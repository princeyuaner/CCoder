**Install:** [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/34281) ·
or download `CCoder-0.2.34.zip` below → Settings → Plugins → ⚙ → Install Plugin from Disk

- **A new session no longer opens on an empty background** — a centered guide card asks
  "What can I help you with?" and shows three ways to start: `@` / `#` references sent
  along with your message, `/` commands, and pasting a screenshot. The card is there
  only in genuinely new sessions (including right after `/clear`); and the old
  "Session ready" note is gone — nothing stays pinned above your first message anymore.
- **The plugin icon is the original mark again, in all three places** — the large icon
  in the plugin list had picked up an orange tile behind the letter; it now matches the
  sidebar and menu icons — same shape, no tile.
- **The MCP settings page updates by itself** — when a server that was still connecting
  finishes, its status flips on its own; previously you had to reopen the settings
  dialog to see it.
- **Rename / delete no longer sit lower than the title in the session list** — the
  trailing icons in a row used to sag below the session name; they are lined up with it
  again.
- **The Usage strip keeps up during a session** — today's tokens and estimated cost
  update as the conversation runs; they used to stay frozen until the IDE was restarted.

- **新会话不再是一片空白** — 居中一张引导卡：「有什么可以帮你的？」与三条上手提示
  — @ / # 引用（随消息一起发出）、/ 命令、粘贴截图。卡只出现在真新会话里

  要重开设置框才看得见。

  会话进行中不动，要重启 IDE 才刷新。
