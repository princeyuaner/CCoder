**Install:** [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/34281) ·
or download `CCoder-0.2.31.zip` below → Settings → Plugins → ⚙ → Install Plugin from Disk

- **Skills in Settings** — a new tab lists every skill the CLI knows about (yours, the
  project's, plugins', built-in), grouped by where they come from and searchable. A switch
  on each row turns a skill off; the two softer modes (list the name only / keep it to your
  own `/` commands) sit in the row's ⋯ menu, next to "open SKILL.md". Plugin skills cannot
  be overridden one by one, so they offer updating or disabling the whole plugin instead.
  Changes go through the CLI's own writer, are re-checked against a fresh session right
  away, and take effect in your **next** session.
- **The MCP page is one card per server now** — name, kind and live status in the card
  header; command or URL, variable key names and the failure reason in the body; edit and
  delete in the footer. Adding or editing opens a dialog that will not save until the fields
  validate; the project's servers and your global ones are kept apart, and the global list
  stays read-only.
- **The "Presets" tab is gone** — presets themselves stay: they still show up in the `/`
  list. There is no screen to add or edit them any more; the ones you have keep working.
- **Markdown tables read properly** — a Chinese first column is no longer squeezed to one
  character per line, and the cell borders are visible again.

**安装**：[JetBrains 市场](https://plugins.jetbrains.com/plugin/34281)，或下载下面的
`CCoder-0.2.31.zip` → 设置 → 插件 → ⚙ → 从磁盘安装插件

- **设置里多了「技能」页** —— CLI 认识的每条技能（我的 / 本项目的 / 插件的 / 内置）
  分组列出、可搜索。行上一颗开关就能关掉；另外两档（只列名字 / 只我能用）在行右端的
  ⋯ 里，旁边就是「打开 SKILL.md」。插件的技能没法逐条覆盖 —— 那几行给的是「更新整个
  插件」「停用整个插件」。改动走 CLI 自己的写手，写完立刻重新核对，**下次开会话**生效。
- **MCP 页改成"一台 server 一张卡片"** —— 卡头是名字、形状与实时状态；卡体是命令或
  URL、变量键名、失败原因；卡脚是编辑与删除。新增 / 编辑走弹窗，校验不过存不了；
  项目里的与全局的分开列，全局那份只读。
- **「预置」页签删了** —— 预置功能本身还在：输入 `/` 时照旧出现在列表里。只是从此
  没有界面能新增 / 编辑它们；已有的照旧可用。
- **Markdown 表格能看了** —— 中文首列不再被长串挤成一列一个字；格线也回来了。
