**Install:** [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/34281) ·
or download `CCoder-0.2.29.zip` below → Settings → Plugins → ⚙ → Install Plugin from Disk

- **Keep a second folder in step with yours** — Settings has a new **Sync** page: pick a
  local folder and a target folder, flip the switch, and every file you add, edit or delete
  is mirrored over while the tool window is open. Nothing happens until you configure it —
  it is off by default. The plugin's own state (baselines, claims) lives in the IDE's system
  directory, **never in your project**, and on the other side it only ever removes files
  **it** copied: if the target's copy was changed by something else, it tells you and leaves
  it alone. Content is compared before anything is touched, so the first check of a large
  folder takes a moment and says so in the log.
- **The sync card tells you what it did** — a card left of **Context** holds the on/off
  switch, and clicking it opens the log. When a round actually moved files, a small bubble
  above the card names up to three of them for three seconds; clicking that opens the same
  log. The log keeps updating in place, so you can leave it open and watch the next round.
- **The group-chat page is gone from Settings** — it was a single QR code; the **Sync** page
  takes that slot.

**安装**：[JetBrains 市场](https://plugins.jetbrains.com/plugin/34281)，或下载下面的
`CCoder-0.2.29.zip` → 设置 → 插件 → ⚙ → 从磁盘安装插件

- **让第二个目录跟着你的目录走** —— 设置里多了一页「**同步**」：选一个本地目录、一个目标
  目录，打开开关，你在本地新增 / 修改 / 删除的文件就会镜像过去（工具窗口开着的时候）。
  **不配置就不开启**（默认关着）。插件自己的状态（基线、认领记录）放在 IDE 的系统目录里，
  **一个字都不写进你的项目**；目标端那边，它只删**自己复制过去的**那些 —— 那份被别的程序
  改过的话，它只提醒、不动手。动手之前先比对内容，所以很大的目录第一次核对要等一下，
  日志里会说明。
- **同步卡把做过的事说出来** —— 上下文左边多了一张卡：开关在卡上，点卡打开日志。一轮真的
  动了文件时，卡上方会冒一句"同步了哪几个文件"（最多三条），**3 秒**后自己关；点它打开的
  就是同一屏日志。日志是**就地更新**的，可以开着它盯下一轮。
- **设置里的「群交流」页签删了** —— 那一页只有一张二维码，位置现在归「同步」。
