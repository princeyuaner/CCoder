- **A grip on the divider above the input** — the drag strip between the transcript and
  the input card now carries a small always-visible handle that lights up on hover, so
  you can tell it resizes without hunting for the edge.
- **The model picker is two columns now** — profiles on the left, the models of the one
  you are browsing on the right. It drops from ~518px tall to ~180px and no longer grows
  with model count. Clicking the left column only changes what the right side shows; the
  dot still marks the profile you are on.
- **The "this turn's changes" card scrolls after five rows** — expanding it no longer
  stretches the card down the transcript; the file list scrolls and the roll-back bar
  stays pinned.
- **Scheduled send** — a clock button in the input toolbar: +30 / 60 / 120 minutes, or a
  time today. The message leaves the box and waits in the transcript as a dashed bubble;
  at that time it presses Send for you (queues if Claude is busy, starts a session if
  none is running). The × cancels it.
- **Usage reads two more accounts** — with an opencode profile selected, the strip and
  the stats dialog show its Go quota (used share per window: 5h / week / month, one bar
  each, with the reset time); with DeepSeek, the account balance (granted and topped up,
  or an amber "unavailable"). The dialog also stops stretching to full-screen width when
  a long model legend used to push it out — the legend wraps now.
- **Card outlines no longer have mismatched corners** — the 1px rounded borders on cards
  (settings, ask cards, the composer) were drawn with a stroke whose anti-aliasing
  differed per corner; they are filled rings now, and all four corners match.
