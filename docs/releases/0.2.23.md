**Install:** [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/34281) ·
or download `CCoder-0.2.23.zip` below → Settings → Plugins → ⚙ → Install Plugin from Disk

- **Settings has been redesigned** — eight icon tabs, each page grouped into rounded cards.
- **Restored transcripts no longer put words in your mouth** — the CLI's own envelopes
  (local command echoes and output, the compaction summary) are no longer replayed as
  messages you had sent.
- **An idle Agents popup answers first** — "no subagents are running", with the finished
  ones behind one clickable "Show N finished ›" line.
- **The connection card marks work done by a subagent** — a small dot next to the icon.
- **Ask cards** — multi-select questions say "Pick any"; picking another answer on a
  single-choice question now clears the previous tick.
