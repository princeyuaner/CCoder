**Install:** [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/34281) ·
or download `CCoder-0.2.38.zip` below → Settings → Plugins → ⚙ → Install Plugin from Disk

- **A "this turn's changes" card** — everything the last round touched, listed above the
  input box. Expand it to check files and roll them back in one batch (confirmation
  happens inside the card); click a row to open a "before ↔ now" diff in the IDE.
  Rolling back never rewrites the conversation — it appends a note. Toggle in
  Settings · General ("keep snapshots of this turn's changes", on by default).
- **A warning strip while MCP servers are still connecting** — right after an IDE
  restart, the first sends can miss the prompt cache and re-bill ~170k tokens at full
  price, because the tool list isn't stable yet. A strip above the input box shows the
  state (connecting / failed / settled); hitting Send too early lets you confirm in
  place (wait / send anyway / stop asking for this session).
- **The usage strip now matches the cards around it** — its corners were only half as
  round as the status cards above and the input card below (its arc was copied from a
  design's radius), and its outline all but vanished against the background. All three
  now share one corner radius, one outline color, one fill.

**安装**：[JetBrains 市场](https://plugins.jetbrains.com/plugin/34281)，或下载下面的
`CCoder-0.2.38.zip` → 设置 → 插件 → ⚙ → 从磁盘安装插件

- **多了「本轮改动」卡** — 上一轮动过哪些文件，输入框上方一眼看到。展开勾选可批量回滚
  （确认在卡内翻）；点一行打开「改动前 ↔ 当前」对比（IDE 原生 Diff）。回滚不动对话
  一个字，只追加一条提示。开关在 设置 · 通用（「保留本轮改动的存档」，默认开）。
- **MCP 还没连完时有条提示带** — 重启 IDE 后头几发可能踩空缓存、十几万 token 按全价
  重算（工具表还没稳定）。输入框上方现在会显示状态（连接中 / 失败 / 已落定）；发早了
  它会就地拦一下，让你选 等它 / 照发 / 本会话不再问。
- **使用量那条与上下两张卡样式统一** — 它的圆角原来只有邻居的一半（抄数时把直径当成了
  半径），描边也淡到左右两边看不见；现在三张卡一个圆角、一种描边、一样的底。
