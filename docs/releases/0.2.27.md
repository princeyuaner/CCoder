**Install:** [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/34281) ·
or download `CCoder-0.2.27.zip` below → Settings → Plugins → ⚙ → Install Plugin from Disk

**Requires IntelliJ 2026.1 or newer** — this release moves the baseline up from 2025.3,
so older IDEs will not be offered it.

- **The conversation view survives a broken embedded browser** — IntelliJ 2025.2+ runs
  JCEF in a separate process, and on the JCEF build that 2026.2 ships that channel drops
  (JBR-9234, an NPE inside `RemoteMessageRouterImpl`). It showed up as "the output area
  stops updating after a while", or as the whole new session blowing up into an exception
  dialog. Three things now stand between you and that: the view **degrades to a page with
  a Retry** instead of taking the session down; a **heartbeat** notices the channel that
  died without saying so; and when the IDE is actually in that mode the page offers a
  **one-click "turn off out-of-process JCEF"** (the fix needs a full IDE restart). A
  session opens with a heads-up first — you hear about it *before* the freeze, not after.
- **Fixed: Shift+Enter makes a newline again** — the input's key map had only plain Enter
  bound to a line break, and Shift+Enter was left to a character event that the IDE drops.
  It is now bound to exactly the same action as plain Enter.
- **Fixed: the input area scrolls once the text outgrows it** — past the visible rows there
  was no scrollbar, so the rest of what you typed was simply unreachable. It fills the area
  while the text fits, and hands over to a scrollbar when it does not.
- **Sessions are cards now** — the current one is marked with an accent bar and a bold
  title, sessions already open elsewhere are dimmed, and eight fit on a screen where ten
  used to.
- **Long tool output no longer chokes the view** — a tool result over 8000 characters is
  truncated with its original length noted, and very large bodies are pushed in chunks
  instead of as one script.
- **Model keys can be copied** — a button beside the key field copies the whole value even
  while it is masked, and confirms with a checkmark. You no longer have to reveal the
  secret in order to copy it.

**安装**：[JetBrains 市场](https://plugins.jetbrains.com/plugin/34281)，或下载下面的
`CCoder-0.2.27.zip` → 设置 → 插件 → ⚙ → 从磁盘安装插件

**要求 IntelliJ 2026.1 或更新** —— 这一版把编译目标从 2025.3 抬了上来，更老的 IDE
不会收到这次更新。

- **内嵌浏览器坏掉时，对话区扛得住了** —— IntelliJ 2025.2 起把 JCEF 放在独立进程里，
  而 2026.2 捆的那版 JCEF 上那条通道会断（JBR-9234，`RemoteMessageRouterImpl` 里的
  空指针）。它表现为"用着用着输出区不动了"，或者干脆把整个新会话带崩成一个异常对话框。
  现在三样东西挡在中间：视图**降级成一张带「重试」的说明页**，不再把会话一起带走；
  **心跳**能发现"断得一声不吭"那种；而真跑在那个模式上时，页上还给一颗
  **一键关掉 out-of-process JCEF** 的键（改完要完全重启 IDE）。会话打开时先提醒一句
  —— 在卡死**之前**说，而不是之后。
- **修好：Shift+Enter 又能换行了** —— 输入框的键表里只有裸 Enter 绑了换行，
  Shift+Enter 靠的是一个会被 IDE 丢掉的字符事件。现在它绑的是和裸 Enter **同一个**动作。
- **修好：文本装不下时输入框出滚动条** —— 从前超出可视区的那部分既看不见也够不着。
  现在装得下就撑满，装不下就交给滚动条。
- **会话列表改成卡片** —— 当前会话有强调条和加粗标题，已在别处打开的会话变淡，
  一屏 8 条（原来 10 条）。
- **超长的工具输出不再把界面压死** —— 工具结果超过 8000 字会截断并标注原长，
  特别大的正文分片推送。
- **模型密钥可以复制了** —— 密钥框旁边一颗键，打码状态下也照复制整条，点完变对勾。
  不必为了复制先把它显示在屏幕上。
