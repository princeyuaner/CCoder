**Install:** [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/34281) ·
or download `CCoder-0.2.25.zip` below → Settings → Plugins → ⚙ → Install Plugin from Disk

- **Tool cards are born when the tool starts** — the card appears as soon as the model
  decides to use a tool (name, spinner, timer), fills in the file name or command as the
  arguments stream in, and takes its check when the result arrives. Reading a file or
  searching used to draw nothing at all until it was over: the card was born already
  finished, so the spinner never got seen. Measured on a real session, a `Read` used to
  have a 21 ms window in which it could have been spinning.
- **The whole context, in one place** — clicking the context card opens a window with the
  per-category breakdown (each row with its share of the window) plus a tab for each of
  MCP tools, memory files, subagents and skills, the count on the tab. Copy it as text
  with one button.
- **Fixed: the first message after switching models no longer disappears** — switching to
  a model on a different endpoint restarts the session behind you, and a late reset wiped
  the message you had just typed. It *had* been sent, so you got an answer with no
  question. Restarting after a disconnect also keeps the transcript on screen now, as it
  was always meant to, and a message typed while the session is still coming up is sent
  once it is ready, instead of never.
- **Fixed: Settings → Models no longer cuts off the list** — with three or four models the
  last row was half visible and "＋ Add model" was out of sight entirely; the list now
  shrinks and scrolls inside the card instead.
