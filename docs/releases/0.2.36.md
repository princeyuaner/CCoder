or download `CCoder-0.2.36.zip` below → Settings → Plugins → ⚙ → Install Plugin from Disk

- **The model / permission / thinking pickers now open under their own button** — all
  three used to pop up at the panel's far left edge, so whichever one you clicked, the
  list appeared somewhere else. Each now drops from its own button, clamped to stay
  inside the panel. The session list picker is unchanged.
- **Moving the selection in the completion popup no longer flashes** — pressing ↑/↓ used
  to rebuild the list and re-open the popup on every keypress, flashing the whole frame;
  the highlight now moves in place, repainting just the two affected rows.
