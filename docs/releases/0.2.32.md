**Install:** [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/34281) ·
or download `CCoder-0.2.32.zip` below → Settings → Plugins → ⚙ → Install Plugin from Disk

- **MCP servers can be reconnected or switched off without restarting the session** —
  while a session is running, the server cards in Settings → MCP gain a **Reconnect** and
  a **Disable**/**Enable** button: bring a server back or switch it off without leaving
  the session. The status is re-read right after, and a failure names the server and the
  reason.
- **Files dropped into the composer become references** — dragging a file onto the input
  box used to paste its path as plain text; now a non-image file becomes an `@` reference
  (images still go to the attachment strip). Files outside the project are written as
  absolute paths — no more `..` chains.

**安装**：[JetBrains 市场](https://plugins.jetbrains.com/plugin/34281)，或下载下面的
`CCoder-0.2.32.zip` → 设置 → 插件 → ⚙ → 从磁盘安装插件

- **MCP server 不重开会话就能重连 / 停用** —— 有会话在跑时，设置 → MCP 里那些 server
  卡上多了「重连」与「停用」（已停用的显示「启用」）两颗按钮：不用离开会话就能把一台
  server 拎回来或关掉。动作之后自动重读一遍状态，失败会点名是哪台、写清原因。
- **拖进输入框的文件变成引用** —— 往输入框拖文件，以前只是把路径当文本插进来；现在
  非图片文件会变成 `@` 引用（图片仍进附件带）。项目外的文件一律写绝对路径 —— 不再
  出现 `..` 串。
