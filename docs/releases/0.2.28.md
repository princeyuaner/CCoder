**Install:** [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/34281) ·
or download `CCoder-0.2.28.zip` below → Settings → Plugins → ⚙ → Install Plugin from Disk

- **See the edit before you approve it** — file edits (Edit / Write / MultiEdit) now draw a
  real diff right in the approval card, rendered by the same rules the transcript uses —
  including `MultiEdit`, which never had one before. A preview over 200 lines falls back to
  plain text (nothing is hidden, it just gets no colours).
- **Sessions can be renamed** — every row in the session list has a **Rename** button, and
  clearing the field restores the automatic title. The session you are chatting in can be
  renamed too.
- **A copied file pastes as a reference** — pressing Ctrl+V in the input box now turns a file
  you copied (in your file manager, or a path copied inside the IDE) into an `@` reference —
  the same thing the attach button produces. Images still land in the attachment strip, and
  ordinary text pastes exactly as it did before.
- **The subagent panel lists only what is running** — one row per running subagent (its type
  and task, with the stop button on the right). Finished ones are no longer listed; reopen
  that session to review their transcripts.
- **Fixed: long command descriptions were cut in half** — once you typed and the matching
  part was highlighted, a row could wrap onto a second line and get clipped by the popup.

- **批准之前先看见改动** —— 文件类的审批（Edit / Write / MultiEdit）现在直接在审批卡里
  画出真正的 diff，规则与转写区逐字一致 —— 包括从前连 diff 都没有的 `MultiEdit`。
  超过 200 行的预览退回纯文本（一个字都不少，只是没有配色）。
- **会话可以改名** —— 会话列表每一行都有**改名**按钮，清空就恢复自动标题；
  正在聊的那一条也能改。
- **复制的文件粘进来就是引用** —— 在输入框里按 Ctrl+V，复制来的文件（资源管理器里复制的，
  或 IDE 里复制的路径）直接变成 `@` 引用 —— 与左下角那颗附件按钮产出的是同一样东西。
  图片照旧进附件带，普通文本一个字不变。
- **子代理浮层只列在跑的** —— 每个在跑的子代理一行（类型 + 任务名，右端可终止）。
  已结束的不再列出 —— 要回看它们的转写请重开那条会话。
- **修好：命令的长描述被裁掉半句** —— 打了字、命中加粗之后，那一行会折行，
  第二行被弹层裁掉。
