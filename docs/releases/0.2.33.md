**Install:** [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/34281) ·
or download `CCoder-0.2.33.zip` below → Settings → Plugins → ⚙ → Install Plugin from Disk

- **Token usage statistics: a daily / weekly / monthly dashboard** — a slim **Usage**
  strip above the input box shows today's tokens and an estimated cost; click it for
  the dashboard: today / this week / this month tiles, a per-model stacked bar chart
  over the last 30 days (switchable to 12 weeks or 12 months), and a per-model
  breakdown table. Costs are estimated from API price tables — not a bill. History
  is back-filled from your local Claude Code session files; the first scan takes a
  few seconds, and it updates incrementally after that.
- **Scrolling up while a reply streams works again** — the transcript no longer snaps
  back to the bottom while you read earlier output; one wheel notch up is enough, and
  following resumes only when you scroll back down.
- **`/clear` also empties the task list card now** — the tasks panel used to keep the
  previous run's counts until the next session boundary.

- **Token 使用量统计：日 / 周 / 月仪表盘** — 输入框上方多了一条「使用量」常驻条，
  显示今日 token 与估算成本；点开是仪表盘：今日 / 本周 / 本月三块砖、近 30 天的
  按模型堆叠柱（可切近 12 周 / 近 12 个月）、按模型的分解表。成本按 API 单价估算，
  不是账单。历史数据从本机 Claude Code 会话文件回填 — 首扫几秒，之后增量更新。
- **流式回复期间向上滚动恢复正常** — 往回读的时候不再被拽回底部；滚轮上滚一格就够，
  滚回底部（或自己发一条）才恢复跟随。
- **`/clear` 现在也会把任务清单卡清空** — 以前清单会挂着上一段的计数，直到下一个
  会话边界。
