**Install:** [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/34281) ·
or download `CCoder-0.2.30.zip` below → Settings → Plugins → ⚙ → Install Plugin from Disk

- **The task card now says how it ended** — it used to answer only "who is running right
  now", and a task simply vanished the moment it finished. It is now three sections:
  **running** / **paused** / **just finished**. Rows that finished keep their outcome
  (done / failed / stopped), how long they took and how many tool calls they made — and
  the reason, when they failed.
- **Read a finished task's output** — the last 200 lines in a dialog, with a button that
  opens the whole file in the editor (search, folding and large files come for free there).
  If the output file is gone — temporary directories do get cleaned up — it says so
  instead of showing an empty box.
- **Right-click a folder in the project view to add it to the chat** — that menu item used
  to be greyed out for folders. It now inserts an `@` reference just like a file
  (`@src/`), and the CLI expands it into the listing of that folder — so a folder costs
  one line rather than the whole tree, and files and folders can be picked in the same go.

- **任务卡现在会说"成了没有"** —— 从前它只回答"眼下有谁在跑"，任务一结束那一行就凭空
  消失。现在分三段：**在跑** / **暂停** / **刚结束**；刚结束的那些留着结局（成了 / 失败 /
  被停掉）、耗时、调了多少次工具，失败的话还有原因。
- **看一个已结束任务的输出** —— 一屏给最后 200 行，旁边一颗按钮把完整那份在编辑器里打开
  （搜索、折叠、大文件都现成）。输出文件不在了（临时目录会被清掉）会**明说**，而不是给
  一个空框。
- **项目树里右键文件夹也能加进聊天框** —— 从前对着文件夹那一项是**灰的**。现在和文件一样
  插一条 `@` 引用（`@src/`），CLI 会把它展开成那个文件夹的文件列表 —— 所以它只占一行、
  不会把整棵树塞进去；文件与文件夹可以一次混着选。
