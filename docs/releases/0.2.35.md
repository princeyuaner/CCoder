**Install:** [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/34281) ·
or download `CCoder-0.2.35.zip` below → Settings → Plugins → ⚙ → Install Plugin from Disk

- **See what you were actually charged, next to the estimate** — when the selected
  model config is a DMXAPI one, the Usage strip gains a `charged ¥8.30` segment and
  the usage dialog a reconciliation bar under the three tiles: charged today, token
  balance, bill tokens, and when the figure was last refreshed (↻ refetches it).
  The number comes from the DMXAPI token ledger — "this token · today" — so it will
  not match the project-scoped estimate beside it, by design. Any other provider:
  nothing changes.
