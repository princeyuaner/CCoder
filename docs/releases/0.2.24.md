**Install:** [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/34281) ·
or download `CCoder-0.2.24.zip` below → Settings → Plugins → ⚙ → Install Plugin from Disk

- **Streaming no longer drags you back to the bottom** — scrolling up while a reply
  streams (or while the model is thinking) now stays where you put it. Before this
  release every frame pulled the view back down, which made reading history during a
  long answer impossible. The "back to bottom" button works as before, and scrolling
  back down, clicking it or sending a message all resume following.
- **Thinking can start collapsed** — a new setting folds thinking text by default,
  **including the block that is still streaming**; the spinner and timer stay in the
  title, and one click expands it. Off by default.
- **A font and size for the transcript** — under Settings → General → Interface: four
  families (plus "follow IDE") and four sizes. They apply to the transcript only; code
  blocks always stay monospaced, and the composer keeps following the IDE.
- **Model, permission mode and thinking effort open as pickers** — the three composer
  switches now share one card look, with group headings (permission modes that never
  ask again; effort levels only some models accept).
- **A tab whose session cannot be reopened says so** — it used to start an empty
  conversation silently; now it tells you (deleted, or already open in another tab).

- **流式输出时向上滚不再被拽回底部** —— 从前每一拍都会把视口弹回最底下，长回答里想往上
  翻历史基本不可能；现在滚上去就停在那儿。「回到底部」按钮照旧，滚回底部、点它、或自己
  发一条都会恢复跟随。
- **思考可以默认收起** —— 新开关让思考内容默认折叠，**正在流式的那块也收起**；标题里的
  转圈与秒表照旧，点一下标题即可展开。默认**不**折叠。
- **转录区能选字体与字号** —— 设置 →「通用」→「界面」卡：四档字体（含「跟随 IDE」）与
  四档字号，只作用在转录区；代码块始终等宽，输入框仍跟随 IDE。
- **模型 / 权限 / 思考深度换成弹层选择** —— 输入区那三个开关共用一套卡面，带分组标题
  （如「不再问你」「仅部分模型认」）。
- **标签页的会话打不开时会说明** —— 从前静默开一个空会话；现在会告诉你（已删除，或已在
  别的标签里开着）。
